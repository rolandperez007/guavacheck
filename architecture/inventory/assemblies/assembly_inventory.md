# Construction Assembly Inventory

## Purpose

Identify every existing and future construction assembly that converts
design intent into measurable construction work.

## Assembly Concept

An assembly is a repeatable construction specification consisting of:

- Assembly identity
- Category
- Components
- Materials
- Labour
- Equipment
- Quantity rule
- Waste factor
- Unit
- Unit rate
- Regional applicability
- Quality tier
- Applicable standards

## Examples

- External wall
- Internal partition
- Floor finish
- Suspended ceiling
- Roof system
- Reinforced concrete slab
- Reinforced concrete beam
- Reinforced concrete column
- Bathroom finish package
- Kitchen finish package
- Electrical installation package
- Plumbing installation package

## Required Flow

Design Element
→ Assembly
→ Component Quantities
→ BOQ Line Items
→ Unit Rates
→ Cost

## Critical Principle

Assemblies are the bridge between the spatial/design model and the BOQ.

No new assembly engine should be implemented until the existing assembly
knowledge has been inventoried.
