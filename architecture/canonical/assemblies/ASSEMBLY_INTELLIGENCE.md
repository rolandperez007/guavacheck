# Canonical Construction Assembly Intelligence

## Purpose

Assemblies convert design intent into measurable construction work.

They are the primary bridge between spatial intelligence and BOQ intelligence.

---

# Assembly

An assembly consists of:

- identity
- code
- category
- description
- components
- materials
- labour
- equipment
- quantity rules
- waste factors
- unit
- regional applicability
- quality tier
- applicable standards

---

# Assembly Pipeline

Design Element
→ Assembly
→ Components
→ Quantity Rules
→ Quantities
→ BOQ

# Assembly Reuse

Assemblies should be reusable.

A single assembly may be used by:

- AI design
- building generation
- BOQ
- estimating
- procurement
- construction planning
- digital twin
- project monitoring

---

# Assembly Principle

Assemblies should describe how something is constructed, not merely how it
looks.
