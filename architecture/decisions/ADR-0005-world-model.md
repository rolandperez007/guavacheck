# ADR-0005: World Model

**Status:** Accepted

**Date:** 2026-07-17

---

# Context

Austin requires a consistent conceptual model of the built environment.

Without a shared understanding of how entities relate, intelligent reasoning becomes inconsistent.

---

# Decision

Austin shall reason using a World Model.

The World Model defines the entities and relationships that describe the built environment.

---

# Core Entities

People

Organizations

Land

Properties

Buildings

Communities

Infrastructure

Cities

Regions

Countries

Natural Environment

Economies

---

# Relationship Examples

People own properties.

Properties belong to communities.

Communities belong to cities.

Cities belong to countries.

Infrastructure serves communities.

Construction transforms land into buildings.

Austin reasons across these relationships.

---

# Consequences

Positive

- Consistent reasoning.
- Unified terminology.
- Scalable architecture.
- Better AI explainability.

Trade-offs

- Continuous maintenance.
- Schema evolution.

---

# Guiding Principle

Austin understands the world through connected entities and relationships.
