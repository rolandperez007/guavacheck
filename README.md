# guavacheck

### Intelligence for Property, Infrastructure and Trust

---

![guavacheck](public/logo-transparent.png)

guavacheck is an intelligent platform designed to simplify property, construction, engineering, infrastructure and investment decisions through the power of artificial intelligence, verification systems and specialized industry engines.

At the center of the platform is **Austin™**, the operating intelligence responsible for orchestrating every subsystem and transforming complex workflows into a simple conversational experience.

# Austin™

Austin is the central intelligence of guavacheck.

Austin is not a chatbot.

Austin is not a plugin.

Austin is not a search engine.

Austin is the orchestration layer responsible for:

- Understanding intent
- Routing requests
- Coordinating engines
- Explaining outcomes
- Monitoring platform health
- Protecting user trust

Every major system inside guavacheck communicates through Austin.

# Installation

Clone the repository:

```bash
git clone https://github.com/your-org/guavacheck.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# Environment Variables

Create:

```bash
.env.local
```

Required variables:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

OPENAI_API_KEY=

DATABASE_URL=

AUSTIN_PROVIDER=
```

Additional providers may be configured through the Austin orchestration layer.
