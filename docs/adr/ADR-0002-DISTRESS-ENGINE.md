# ADR-002

## Title

Property Passport as the Canonical Identity

---

## Status

Accepted

---

## Context

Property information changes over time.

Ownership changes.

Twins evolve.

Construction progresses.

A permanent identity is required.

---

## Decision

Every property receives exactly one Property Passport.

The Passport becomes the canonical identity for the platform.

Every engine references the Passport.

---

## Consequences

Stable identity

Consistent references

Simplified integrations

Permanent history
