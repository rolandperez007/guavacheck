# ADR-003

## Title

Digital Twin as a Dedicated Engine

---

## Status

Accepted

---

## Context

Three-dimensional property information continues to grow.

A dedicated engine is required.

---

## Decision

Twin Studio becomes an independent platform engine.

Twin Studio owns

• Geometry

• Components

• Versions

• Assets

• Inspections

Twin Studio never owns ownership information.

---

## Consequences

Clear responsibility

Independent scaling

Improved rendering

Future IoT integration
