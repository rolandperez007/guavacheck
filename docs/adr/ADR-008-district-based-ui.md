# ADR-008

## Title

District-Based User Experience

---

## Status

Accepted

---

## Context

Users interact with different aspects of the property ecosystem.

A flat navigation structure becomes difficult to scale.

---

## Decision

Guava adopts a city-based navigation model.

Districts include

Residential

Commerce

Finance

Construction

Investor

Trust Exchange

Distress

Knowledge

Each district represents a specialised platform capability while sharing the same underlying engines.

---

## Consequences

Improved navigation

Scalable user experience

Clear mental model

Supports future expansion without redesigning the platform
