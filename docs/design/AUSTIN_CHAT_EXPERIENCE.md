\# Austin Chat Experience



> Official conversational experience for Austin inside the Guava Dashboard.



\---



\# Vision



Austin is not a separate application.



Austin is part of Guava City.



The user should feel like they are speaking to an intelligent property partner while remaining inside their working environment.



Austin assists without interrupting the dashboard experience.



\---



\# Design Principle



The dashboard is the primary workspace.



Austin is the intelligent assistant embedded within it.



The dashboard never disappears simply because the user asked a question.



\---



\# Primary Conversation Surface



The hero card located at the center of the dashboard contains Austin.



```

Hi David,



I'm Austin 👋



Your AI Property Partner.



\[ Ask Austin anything... ]

```



This input is always visible.



\---



\# Quick Questions



Users should comfortably ask:



\- Find me a duplex in Lekki.

\- Estimate construction cost.

\- Verify this property.

\- Calculate mortgage.

\- Compare Ikoyi and Banana Island.

\- Recommend contractors.

\- Show distressed sales.

\- Find investment opportunities.



Austin answers directly inside the hero card.



The dashboard remains fully visible.



\---



\# Inline Conversation



The hero expands vertically.



Example



\------------------------------------------------



Hi David



I'm Austin



User:

Find me 4-bedroom duplexes.



Austin:



I found 24 matching properties in Lekki.



• Average Price



• Top Developers



• Investment Rating



\[ View Properties ]



\------------------------------------------------



The conversation occupies only the hero area.



Everything else remains usable.



\---



\# Conversation Length



The hero conversation is intended for:



Quick questions



Fast answers



Immediate guidance



Simple follow-up questions



It is not intended for long collaborative work.



\---



\# Transition to Workspace



When Austin detects that the conversation is becoming larger, a subtle action appears.



Example



──────────────────────────



Continue in Austin Workspace →



──────────────────────────



The user may also manually select:



Open Workspace



Move to Sidebar



Continue Conversation



All perform the same action.



\---



\# Sidebar Experience



Selecting "Continue in Workspace" opens a right-hand sidebar.



The dashboard remains visible.



```

Dashboard



\--------------------------------------------------



&#x20;               | Austin Workspace



&#x20;               |



&#x20;               | Conversation



&#x20;               |



&#x20;               | Files



&#x20;               |



&#x20;               | Images



&#x20;               |



&#x20;               | Property Results



&#x20;               |



&#x20;               | Actions



&#x20;               |



\--------------------------------------------------

```



The user never loses context.

Approximately 420–480 px



Responsive on smaller displays.

Long conversations

Multi-step workflows



Everything beyond a simple answer.



\---



\# Moving Between Modes



Users may:



Collapse Sidebar



Expand Sidebar



Pin Sidebar



Close Sidebar



Reopen Conversation



Conversation state is preserved.



\---



\# Dashboard Remains Interactive



Even with Austin open:



Navigation works.



Marketplace works.



Finance works.



Notifications work.



Reports work.



Projects remain accessible.



Austin never blocks the application.



\---



\# Austin Responses



Responses should feel conversational.



Not robotic.



Not overly verbose.



Professional.



Helpful.



Context-aware.



Austin behaves like an experienced property consultant.



\---



\# Suggested Actions



After every answer Austin may present action chips.



Examples



View Property



Generate Passport



Estimate Cost



Find Contractor



Compare Locations



Finance Options



Schedule Inspection



These actions launch workflows directly.



\---



\# Context Awareness



Austin understands the current page.



Examples



If the user is inside Marketplace:



Austin knows they are browsing properties.



If inside Finance:



Austin assumes financing context.



If inside Verification:



Austin understands ownership verification.



Austin should not repeatedly ask for information already visible on the screen.



\---



\# Persistent Memory



The active conversation continues while navigating.



Changing pages should not erase the conversation.



Austin remembers:



Current project



Current property



Current filters



Current workflow



Recent questions



until the session ends.



\---



\# Multi-Tasking



Users may continue working while Austin thinks.



Austin can process:



Property searches



Verification



Cost estimation



Image generation



Market analysis



without blocking dashboard interaction.



\---



\# Notifications



When Austin finishes a long-running task:



A small notification appears.



Example



✓ Construction estimate completed.



Open Results →



No intrusive modal should appear.



\---



\# Mobile Behaviour



On mobile:



Austin opens as a full-screen sheet.



Closing the sheet returns the user to the exact dashboard position.



Conversation remains active.



\---



\# Motion



Hero expansion:



200 ms



Sidebar slide:



250 ms



Collapse:



180 ms



All motion should be calm and premium.



\---



\# Visual Rules



Do not redesign the dashboard.



Do not reposition Austin.



Do not change card sizes.



Do not introduce floating chat bubbles.



Do not copy ChatGPT.



Austin belongs inside Guava City.



The dashboard remains the primary interface.



\---



\# Design Philosophy



Austin should feel less like opening another application and more like speaking with the intelligence that powers the city itself.



The conversation begins naturally inside the dashboard.



Only when the user chooses does it evolve into a dedicated workspace.



This preserves focus, maintains productivity, and keeps Guava City at the center of the experience.
