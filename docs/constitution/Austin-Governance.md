# Overview

Austin is not governed by models.

Austin is not governed by engines.

Austin is governed by the Kernel.

The Kernel enforces constitutional authority over every persistent state mutation.

Governance is therefore not an application feature.

Governance is a runtime property.

The Governance Layer exists to guarantee that intelligence remains:

- trustworthy

- explainable

- constitutional

- observable

- accountable

Every engine operates under governance.

No engine governs itself.

# Constitutional Outcomes

## Commit

The mutation becomes permanent.

Persistent Cognitive Space is updated.

The Event Ledger records the mutation.

The Knowledge Graph is updated.

The Provenance DAG records lineage.

---

## Rollback

The mutation is rejected.

Persistent memory remains unchanged.

Working Cognitive Space may continue reasoning.

---

## Suspend

The mutation remains unresolved.

The Working Cognitive Space is preserved.

The system waits for additional observation or external evidence.

Suspend is not failure.

Suspend preserves epistemic integrity.
