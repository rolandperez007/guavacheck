# Vision

The Marketplace is the commercial district of guavacheck.

It allows verified institutions, businesses, artisans, contractors, manufacturers, and service providers to participate in the property lifecycle.

Marketplace activity is trusted because it is built upon verified identities, Property Passports, institutional governance, and workflow automation.
