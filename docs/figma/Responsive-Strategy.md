# Layout Philosophy

Desktop

Mission Control remains visible.

Austin remains available.

Sidebar stays expanded.

---

Tablet

Sidebar collapses.

Austin becomes docked.

Cards resize intelligently.

---

Mobile

Mission Control becomes stacked.

Austin remains floating.

Navigation moves to bottom.
