# Agent Message Types

## Task Request

A request for another agent to perform analysis.

Example:

Architecture Agent requests:

"Evaluate structural feasibility."

---

## Data Request

Request for information.

Example:

Finance Agent requests:

"Provide construction cost estimate."

---

## Recommendation Message

Agent provides a proposed solution.

Example:

Materials Agent:

"Use recycled steel due to cost and sustainability advantages."

---

## Warning Message

Agent identifies risk.

Example:

Construction Agent:

"Material delivery delay may affect schedule."

---

## Decision Message

Approved action.

Example:

"Change procurement strategy."
