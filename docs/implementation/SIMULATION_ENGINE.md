# Vision

The Simulation Engine allows users to explore the future before making real-world decisions.

Every important property decision can be simulated.

Every financial decision can be modeled.

Every construction project can be tested.

Every investment can be stress-tested.

Every recommendation generated by Austin should be supported by one or more simulations.

Simulation replaces guessing with evidence.
