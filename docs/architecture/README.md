# GuavaCheck Enterprise Architecture

This directory contains the architectural reference for the GuavaCheck platform.

Its purpose is to provide a single source of truth for:

- Engineers
- Architects
- AI Assistants
- GitHub Copilot
- Technical Writers
- Product Teams

These documents describe how the platform is structured, how modules communicate, and the architectural principles that guide implementation.

The documentation should always reflect the current implementation and evolve with the platform.
