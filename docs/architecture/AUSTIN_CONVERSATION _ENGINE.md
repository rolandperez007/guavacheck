# Austin Conversation Engine
Version: 1.0

# Vision

Austin is not a chatbot.

Austin is the operating intelligence of GuavaCheck.

Every screen can summon Austin.

Every workflow can invoke Austin.

Every institution can customize Austin.

Every recommendation can be explained by Austin.

Users should eventually forget they are navigating menus.

Instead...

they simply ask.
