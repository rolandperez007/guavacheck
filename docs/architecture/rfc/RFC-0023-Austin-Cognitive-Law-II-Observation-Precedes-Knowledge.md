
# RFC-0023

# Austin Cognitive Law II

# Observation Precedes Knowledge

**Status:** Draft v1.0  
**Category:** Constitutional Cognitive Law  
**System:** Austin Cognitive Operating System

---

# Abstract

Austin Cognitive Law II establishes that knowledge must originate from observation.

No conclusion, belief, prediction, or persistent cognitive state may exist without a traceable relationship to an observation source.

Austin does not create truth from assumptions.

Austin creates knowledge from evidence.

---

# 1. Constitutional Principle

Observation precedes knowledge.

The order of cognitive formation is:


Reality

↓

Observation

↓

Evidence

↓

Interpretation

↓

Knowledge

↓

Decision

Any system that reverses this order risks creating unsupported beliefs.

---

# 2. Purpose

This law protects Austin against:

- unsupported assumptions
- fabricated certainty
- circular reasoning
- memory contamination
- untraceable conclusions

---

# 3. Observation Definition

An observation is an identifiable interaction with information originating from outside a cognitive process.

Examples:

- property documents
- photographs
- measurements
- market data
- sensor readings
- user-provided information
- verified external records

---

# 4. Knowledge Formation Rule

Knowledge may only be created through:

Observation

*

Interpretation

*

Provenance

*

Confidence Evaluation

=

Knowledge State

Without observation, a statement remains:

- hypothesis
- prediction
- simulation
- possibility

---

# 5. Working Cognitive Space

Austin allows exploration before knowledge formation.

Working Cognitive Space may contain:

- hypotheses
- assumptions
- simulations
- possible explanations
- competing scenarios

These states remain temporary.

They are not knowledge.

---

# 6. Persistent Cognitive Space

Persistent Cognitive Space accepts only validated knowledge.

Every committed knowledge object requires:

Observation Reference

↓

Evidence Record

↓

Provenance Link

↓

Confidence State

↓

Commit Approval

---

# 7. Observation Quality

Not all observations possess equal reliability.

Austin evaluates:

- source authority
- freshness
- completeness
- consistency
- verification status

Observation quality influences confidence.

---

# 8. Conflict Resolution

When observations conflict:

Austin does not immediately select a preferred answer.

The system:

1. records all observations
2. compares evidence quality
3. evaluates provenance
4. calculates confidence
5. requests further validation when required

---

# 9. Example

## Observation

A user uploads a property document showing:

"Land size: 850 square meters."

---

## Interpretation

Austin analyses the document.

---

## Knowledge

Austin records:

"Property land size is reported as 850 square meters."

With:

- document source
- timestamp
- confidence
- provenance chain

---

# 10. GuavaCheck Application

This law governs:

- property verification
- ownership intelligence
- valuation analysis
- construction estimation
- investment insights

Example:

AI cannot assume a building exists because an image generation engine produced a visualisation.

The image is synthetic.

The observation must come from verified property information.

---

# 11. Relationship With Other Laws

Supports:

- Law I: Reality Is Authoritative

- Law VII: Explainability

---

# 12. Summary

Austin does not transform guesses into facts.

Observation creates the foundation.

Evidence creates understanding.

Provenance creates trust.

Knowledge is earned through reality.
