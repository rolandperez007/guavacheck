# Nigeria 🇳🇬

# Overview

Nigeria is Africa's largest economy by GDP and the continent's most populous nation, serving as one of the world's fastest-growing real estate, infrastructure, and construction markets. It is the primary reference country for the Guava World Engine and acts as the master template for documenting all other countries.
