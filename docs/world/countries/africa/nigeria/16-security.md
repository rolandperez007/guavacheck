# Nigeria — Security

# Purpose

This document defines Nigeria's security landscape, emergency services, disaster risks, fraud indicators, public safety infrastructure, and property risk intelligence for the Guava World Engine.

Austin uses this information to evaluate neighbourhood safety, investment risk, construction security, fraud probability, and emergency preparedness.
